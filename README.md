# OL-LE Studio

Приложение для Windows: скачивание видео и аудио, создание инструментальных версий и отделение вокала.

[Скачать последнюю версию](https://github.com/ragelt/OL-LE-Studio-Releases/releases/latest)

Скачайте OL-LE-Studio.exe и поместите его в отдельную папку. Нужные компоненты установите через кнопку «Обновить» в приложении.

При обновлении заменяйте EXE в папке существующей программы: остальные компоненты сохранятся. Версии 1.0.0 и 1.0.1 нужно один раз обновить вручную до 1.0.2. Начиная с 1.0.2 программа сама проверяет новые версии в этом репозитории.
